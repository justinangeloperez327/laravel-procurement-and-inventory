# GPIMS — Government Procurement and Inventory Management System

Documentation-first Laravel procurement and inventory application based on RA 12009 and applicable implementing regulations.

**Status:** Laravel 13 + Filament 5 scaffold (phase 0) and identity/organization module (phase 1: roles, scoped permissions, delegation, append-only audit) implemented. See [docs/20-PHASE-1-STATUS.md](docs/20-PHASE-1-STATUS.md).

See the `docs/` directory for legal traceability, requirements, workflows, architecture, roadmap, testing, and deployment planning.

> Planning materials are not legal certification. Verify the effective IRR, current GPPB issuances and applicable COA/DBM/DICT requirements before enabling compliance rules.
