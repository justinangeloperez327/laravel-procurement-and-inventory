# 11 — Property Management

Separate consumable inventory, semi-expendable property and PPE using applicable COA classification and threshold rules; never derive property classification only from procurement method.

Asset record: property number, acquisition record, item, purchase cost, condition, serial number, location, custodian, warranty, assignment history.

Lifecycle: accepted delivery → classification → registration → acknowledged assignment → maintenance, inspection and transfer → approved return/disposal. Use applicable ICS/PAR/PTR and other COA forms after validating current versions. Conduct periodic physical counts and reconcile differences.
