# 12 — Document Register

| Stage | Proposed documents |
| --- | --- |
| Planning | Market scoping, PPMP, APP and revisions |
| Request | PR and budget certification |
| Solicitation | RFQ, ITB, bidding documents, specifications, TOR, bulletins |
| Evaluation | Quotation abstract, evaluation, qualification, BAC resolutions and minutes |
| Award | NOA, contract, PO, NTP, performance/warranty security |
| Receipt | Delivery receipt, IAR, discrepancy report |
| Stock | RIS, RSMI, stock card, supplies ledger card, RPCI |
| Property | ICS, PAR, PTR, RPCPPE, IIRUP |
| Finance | Invoice, ORS/BURS, DV and payment references |
| Governance | Protests, COI, beneficial ownership, PMR and audit evidence |

Each record should carry classification, version, author, signer, signed timestamp, retention policy, storage key, SHA-256 hash and transaction reference. Confirm official COA/GPPB templates, requirements and retention durations before generation. No invented signatures or silent overwrites.
